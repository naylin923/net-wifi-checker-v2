Manual ထည့်ခြင်းနှင့် CSV ဖြင့် အများအပြားထည့်ခြင်း။ Admin Token ကို Cloudflare ထဲတွင် သတ်မှတ်ထားသော တန်ဖိုးအတိုင်း ထည့်ပါ။

Token ကို အခြားသူများနှင့် မမျှဝေပါနှင့်။

Voucher တစ်ခု ထည့်ရန်

CSV ဖိုင်ဖြင့် Import လုပ်ရန်

CSV column အစီအစဉ်: code,status,period,expired_at။ Header row ပါလျှင်လည်း ရပါသည်။

Status တန်ဖိုးများ: active, used, expired, disabled. ရှိပြီးသား code တူလျှင် အချက်အလက်ကို update လုပ်မည်။
